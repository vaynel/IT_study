# 개인 재무 및 자산 관리 플랫폼 개발 기획서 (1차)

## 1. 개요

개인 금융 데이터를 통합하여 관리하는 **셀프 호스팅 기반 개인 재무 관리 플랫폼**을 개발한다.

본 서비스는 다음을 목표로 한다.

* 개인의 **현금흐름 관리**
* **카드 사용 내역 분석**
* **투자 자산 관리**
* **자동화 기반 데이터 수집**
* **모바일 친화적인 UI**

서비스는 홈서버 환경에서 운영되며 웹과 모바일 환경에서 모두 사용할 수 있도록 설계한다.

핵심 방향은 다음과 같다.

* 수동 입력 중심의 가계부가 아닌 **자동 데이터 수집 기반 금융 관리**
* 데이터 입력보다 **자동화 및 분석 중심 시스템**
* 개인 환경에서 운영 가능한 **Self-hosted 구조**

---

# 2. 개발 목표

## 2.1 핵심 목표

다음 세 가지 금융 데이터를 통합 관리한다.

### 1. 현금 흐름 관리

개인의 수입 및 지출 흐름을 관리한다.

대상 데이터

* 월급
* 계좌 입출금
* 자동이체
* 생활비 지출
* 정기 지출
* 계좌 간 이체

목표

* 월별 현금흐름 분석
* 고정비 분석
* 소비 패턴 분석

---

### 2. 카드 사용 분석

카드 승인 및 결제 데이터를 관리한다.

대상 데이터

* 카드 승인 내역
* 카드 취소 내역
* 카드 결제 내역
* 카드별 사용 통계

목표

* 소비 분석
* 카드별 사용 통계
* 월별 소비 추이 분석

---

### 3. 투자 자산 관리

투자 자산을 통합 관리한다.

대상 데이터

* 주식
* ETF
* 배당
* 투자 계좌 잔액

목표

* 자산 포트폴리오 분석
* 투자 수익률 계산
* 순자산(Net Worth) 계산

---

# 3. 주요 기능

## 3.1 데이터 수집

다양한 방식으로 금융 데이터를 수집한다.

### CSV / Excel 업로드

지원 데이터

* 은행 거래 내역
* 카드 사용 내역
* 증권 거래 내역

기능

* 파일 업로드
* 자동 파싱
* 데이터 정규화
* 중복 데이터 제거

---

### 이메일 자동 수집

금융 기관에서 발송하는 이메일을 자동으로 처리한다.

예시

* 카드 승인 알림 메일
* 증권 체결 메일
* 거래 내역 이메일

기능

* 이메일 자동 수집
* 첨부파일 파싱
* 자동 거래 생성

---

### 정기 자동 수집

시스템이 주기적으로 데이터를 수집한다.

예시

* 주식 시세
* 환율
* 자산 평가

---

# 4. 자동화 시스템

본 서비스의 핵심은 자동화이다.

자동화 시스템은 다음 기능을 수행한다.

### 거래 자동 분류

거래 데이터를 자동으로 분류한다.

예시

스타벅스 → 카페
쿠팡 → 쇼핑
넷플릭스 → 구독 서비스

분류 기준

* 가맹점 이름
* 키워드
* 금액 패턴
* 거래 계좌

---

### 반복 거래 자동 생성

정기 거래를 자동 생성한다.

예시

* 월세
* 구독 서비스
* 보험
* 정기 저축

---

### 데이터 중복 제거

동일 거래가 중복 등록되는 것을 방지한다.

기준 예시

* 거래일시
* 금액
* 거래처
* 계좌

---

# 5. 주요 화면 구성

표시 정보

* 투자 자산
* 자산 배분

---

## 5.2 거래 내역

모든 거래 내역을 관리한다.

기능

* 거래 수정
* 거래 검색
* 거래 필터

---

## 5.3 자산 관리

사용자의 금융 계좌를 관리한다.

관리 대상

* 은행 계좌

* 증권 계좌

---

투자 자산을 관리한다.

---

금융 데이터를 분석한다.

제공 리포트

* 월별 소비 분석
* 카테고리 소비 분석
* 자산 변화 추이
* 투자 성과 분석

# 6. 시스템 아키텍처

서비스는 다음 구조로 구성된다.

```
Frontend (Web / Mobile)

        │

Backend API Server

        │

Database (PostgreSQL)

        │

Automation Worker

        │

External Data Sources
```

---

## 구성 요소

### Frontend

기능

* 대시보드
* 거래 관리

* 리포트

---

서비스 핵심 로직을 담당한다.

기능

* 데이터 처리
* API 제공
* 인증 처리

---

### Database

모든 금융 데이터를 저장한다.

---

### Automation Worker

자동화 작업을 수행한다.

예시

* 이메일 수집
* 파일 파싱
* 시세 수집
