# 프로젝트 기획서 (Project Charter)

## 1. 프로젝트 개요 (Overview)
- **프로젝트명:** MyFin (Personal Finance & Auto-Trading System)
- **작성자:** 김재현
- **작성일 / 버전:** 2026. 04. 18 / v0.1
- **프로젝트 배경 및 목적**
    - **목적:** 흩어져 있는 개인 자산의 통합 관리 및 사용자 정의 알고리즘을 통한 주식 자동 매매로 안정적인 자산 증식 도모
    - **배경:** 복잡한 금융 데이터를 한눈에 파악하고, 감정에 휘둘리지 않는 기계적 매매를 통해 효율적인 자산 형성 환경 구축

## 2. 목표 및 기대 효과 (Goals & ROI)
- **비즈니스 목표 (Business Objectives):**
    - 실시간 자산 현황 모니터링 및 시각화 기능 구현
    - 백테스팅을 통해 검증된 주식 자동 매매 알고리즘의 안정적 가동
    - 데이터 기반의 합리적인 소비 및 투자 의사결정 지원
- **핵심 성과 지표 (KPIs):**
    - 연간 목표 수익률(ROI) 달성 (예: 시장 지수 대비 +5~10%)
    - 시스템 가동률 99.9% 유지 (API 통신 및 매매 로직 안정성)
    - 수동 관리 대비 자산 관리 시간 70% 이상 단축
- **기대 효과 및 산출물:**
    - 정서적 스트레스 없는 자산 증식 프로세스 확립
    - 산출물: 웹/모바일 기반 대시보드, 자동 매매 봇 엔진, 자산 분석 보고서

## 3. 프로젝트 범위 (Scope)
- **포함되는 범위 (In-Scope):**
    - 주요 증권사 API 연동 (국내/해외 주식 매매 기능)
    - 은행 및 카드사 오픈 API 연동을 통한 지출 내역 수집
    - 사용자 정의 매매 전략 설정 및 백테스팅 엔진
    - 자산 포트폴리오 비중 시각화 및 알림 서비스(Telegram, Slack 등)
- **제외되는 범위 (Out-of-Scope):**
    - 가상자산(Crypto) 매매 (추후 확장 고려)
    - 복잡한 세무 신고 자동화 기능
    - 다중 사용자 지원 (초기 버전은 개인용 시스템으로 한정)

## 4. 주요 이해관계자 및 역할 (Stakeholders & Roles)
- **프로젝트 스폰서:** 김재현 (개인 투자자 및 의사결정자)
- **프로젝트 매니저(PM):** 김재현 (일정 관리 및 요구사항 정의)
- **개발 및 보안 담당자:** 김재현 (시스템 아키텍처 설계, 알고리즘 개발, API 보안 및 데이터 암호화)

## 5. 주요 리스크 및 대응 방안 (Risks & Mitigation)
- **예상 리스크:**
    - **기술적 리스크:** 증권사 API 명세 변경 또는 서버 점검으로 인한 매매 지연
    - **시장 리스크:** 급격한 시장 변동성으로 인한 알고리즘 오작동 및 손실 발생
    - **보안 리스크:** 금융 API 키 유출 및 개인 금융 데이터 해킹 시도
- **대응 및 완화 전략:**
    - **기술적 대응:** 예외 처리 로직 강화 및 시스템 상태 실시간 모니터링/알림 구축
    - **시장 대응:** 엄격한 손절(Stop-loss) 라인 설정 및 알고리즘 상시 업데이트
    - **보안 대응:** API 키 환경변수 관리, 데이터베이스 암호화, 2단계 인증(2FA) 적용
